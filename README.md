# 사회연대경제기업 업무진단도구

사회연대경제기업이 **AI·자동화로 줄일 수 있는 반복업무**를 스스로 점검하고, **유형별 어려움**을 같은 기준으로 기록하는 웹 진단도구입니다.
광명시 사회연대경제센터 마주센터의 AI 활동가 활동에 쓰기 위해 만들었습니다.

**바로 사용하기:** https://charlychae7-lang.github.io/sse-work-diagnosis/

## 구성 (약 25분)

| 단계 | 내용 |
|---|---|
| 1부 기업 현황 | 인증 유형, 규모, 수입원, 업무 도구 |
| 2부 자동화 진단 | 매출·비용 정리와 월간 보고를 5개 기준(25점)으로 평가 |
| 3부 어려움 체크리스트 | A 제품 제조·판매형 / B 서비스 제공형 / C 기타·복합형 문항 |
| 4부 현장 청취 | 가장 큰 어려움 3순위, 지원사업 경험, AI 활용 수준, 바라는 점 |

- 결과 화면에서 맞춤 개선 제안 1장을 바로 인쇄·PDF로 저장할 수 있습니다.
- '응답 모음·집계' 탭에서 유형별 집계를 보고 CSV로 내려받을 수 있습니다.
- 화면 왼쪽 위 '사용 안내'에 사용자 매뉴얼과 유저 스토리가 있습니다.

## 개인정보

서버가 없는 정적 웹페이지입니다. 입력한 내용은 **사용 중인 기기의 브라우저에만 저장**되며 외부로 전송되지 않습니다.
계좌번호 등 민감한 개인정보는 입력하지 마세요. 공용 PC에서는 사용 후 '전체 삭제'를 눌러 주세요.

## 직접 사용하기

`index.html` 파일 하나가 전부입니다. 내려받아 브라우저에서 열면 됩니다. 설치나 서버가 필요 없습니다.
